# 📞 Telco Customer Churn Prediction

# Présentation du projet

Dans ce projet, nous avons développé un modèle de Machine Learning pour prédire si un client d'une entreprise de télécommunications est susceptible de résilier son contrat (churn).
L'objectif est d'aider les équipes commerciales à anticiper les départs clients et mettre en place des stratégies de fidélisation.

# 🛠️ Technologies utilisées
* Python 3.11

* Pandas, NumPy

* Scikit-learn (Logistic Regression, Scaling)

* XGBoost, LightGBM, Gradient Boosting, SVM

* Streamlit (développement de l'application web)

* Matplotlib, Seaborn (visualisations)

# 📊 Workflow du projet
### 1. Exploration et nettoyage des données :

* Gestion des variables numériques et catégorielles

* Suppression des anomalies et valeurs manquantes

* Feature Engineering sur la variable tenure

### 2. Modélisation Machine Learning :

* Régression Logistique

* XGBoost

* Gradient Boosting

* Support Vector Classifier

* LightGBM

Gestion du déséquilibre avec class_weight et scale_pos_weight

### 3. Évaluation des modèles :

* Accuracy, Precision, Recall, F1-Score, ROC-AUC

* Matrices de confusion et courbes ROC

### 4. Application Web Streamlit :

* Formulaire dynamique pour entrer les informations du client

* Prédiction automatique du churn

* Interface personnalisée avec un thème moderne
